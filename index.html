ONVIF
Discover probes the LAN. Authenticate sends login to the server. Configure reads the device with that login and saves name, site, and group. Test checks that saved camera without opening a stream. Review confirms the non-secret summary, then Success marks the camera ready for Live View in a later unit.
Discover
Search this network for ONVIF devices. Results stay off the camera list until you add one yourself.
Authenticate
Choose a discovered device and send its login to the server. The password is cleared on submit and is not shown again.

Select a discovered device.

Configure
Read the device with the login stored on the server, then save a name, site, and group. No password is entered here, and no stream is opened.

Select an authenticated camera.

Test
Uses the login stored on the server. Network, authentication, ONVIF, and saved device info are checked. Stream, audio, PTZ, and event checks are not run.

Review
Confirm the saved name, site, group, manufacturer, model, profile, and last test. No password is shown, and no stream is opened.

Success
After review, mark the camera ready for Live View in a later unit. This does not open a stream.
